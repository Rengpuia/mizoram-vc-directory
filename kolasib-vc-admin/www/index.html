How to open in Google Sheets:

  1. Click Download Google Sheet CSV above (or Copy CSV).
  2. Go to Google Sheets and create a new blank sheet.
  3. Click File > Import > Upload and drop the downloaded file, or paste directly into cell A1.
  4. Choose "Replace spreadsheet" and click Import data.
Set link sharing to "Anyone with the link can view" in Google Sheets.
Exported from Google Sheets via: File > Download > Comma Separated Values (.csv)
You can copy cells directly from Google Sheets / Excel and paste them here.
Imported data will instantly push to all live citizen phonebooks via Server-Sent Events.
